## 1. 시작하기

탭 `시작하기`가 해야 할 일을 **✓ / ✗** 로 보여 줍니다. 필수가 모두 ✓면 준비 끝입니다.

| 순서 | 할 일 | 어디서 | 요령 |
|:---:|---|---|---|
| ① | 카테고리·사용자·예산 | `설정` | 분홍 칸만 고치면 나머지는 자동 |
| ② | 통장·카드·현금·초기 잔액 | `자산` | 카드 이름에 카드사 이름 포함 (예: `신한카드`). 대출은 종류 `대출`, 초기 잔액은 **마이너스** |
| ③ | 소유자 | `자산` I열 | 부부 정산·카드 문자 매칭에 쓰임 |
| ④ | 목표 | `설정` J8~J10 | 목표 순자산·기한(예 `2029-12`)·올해 저축 목표 → `자산현황`에 달성률 |
| ⑤ | 반복 지출 | `반복` | 월급·월세·보험·대출 상환(구분 `이체`: 통장→대출) |
| ⑥ | 증권 키 | 메뉴 `증권 연동` | 각자 PC에서 (→ [5. 증권 연동](#5-증권-연동)) |

📱 **폰 설정** — 구글 시트 앱 설치 → 가계부 열기 → 오른쪽 위 ⋮ → **홈 화면에 추가**(안드로이드) / 즐겨찾기(아이폰).

## 2. 입력하기

### 어떤 방법이 맞을까?

| 상황 | 추천 | 한 줄 |
|---|---|---|
| 지금 막 쓴 돈 (폰) | **빠른입력** | 폼에서 고르고 체크 |
| 문자가 쌓였을 때 | **문자입력** | 여러 건 붙여넣고 체크 |
| 늘 같은 지출 | **즐겨찾기** | 체크 한 번 |
| 매달 같은 날 나가는 돈 | **반복** | 등록해 두면 자동 |
| 나머지·수정 | **내역** | 맨 아래 빈 줄에 직접 |

### ✍️ 내역 (직접 입력)

맨 아래 빈 줄에 한 줄씩. 구분에 따라 줄 색이 칠해집니다 — **수입 빨강 · 지출 파랑 · 저축 노랑**.

| 칸 | 입력 방법 |
|---|---|
| 날짜 | 두 번 누르면 달력. `10/16`처럼 써도 올해로 인식 |
| 사용자 | 신랑 / 신부 / **공동** (같이 쓴 돈) |
| 구분 | 수입 / 지출 / **이체** (내 돈끼리 옮길 때 — `입금자산`도 채움) |
| 카테고리 | 구분을 먼저 고르면 그 구분의 카테고리만 나옴 |
| 결제수단 | `자산`에 등록한 이름만 선택 가능 |
| 금액 | 숫자만 (원). 쉼표 자동 |
| 통화 | 원화는 비움. 외화(USD·JPY·EUR·CNY)는 고르고 **그 통화 금액**을 적기 → 원화금액 자동. 환율은 입력 시점 값이 `적용 환율`에 **고정** |
| 메모 | 가게 이름 등. 카테고리를 비워 두면 과거 같은 메모로 **자동 추천** |

회색 칸(원화금액·귀속월·대분류)은 자동 계산이라 건드리지 마세요. 줄을 고치거나 지우면 대시보드에 바로 반영됩니다.

> 🔴 **빨간 줄** = 날짜·금액 형식 오류(`날짜오류`·`금액오류`·`환율오류`) 또는 사용자 빈칸. 고치기 전에는 합계에서 빠집니다.

### 📱 빠른입력

1. 날짜(비우면 오늘) · 사용자 · 구분 · 카테고리 · 금액 · 통화 · 결제수단 · 입금자산(이체만) · 메모를 고르고
2. 맨 아래 **추가** 체크 → `내역`에 들어갑니다.

사용자·구분·결제수단은 남아 있어 다음 입력이 빠릅니다. 메모를 쓰면 카테고리를 추천해 줍니다.

### 💬 문자입력

`A2`부터 문자를 **여러 건** 붙여넣고 `B1` 체크. 결과는 `C1`에 요약됩니다.

| 문자 종류 | 들어가는 방식 |
|---|---|
| 카드 승인 | 날짜·금액·가맹점 → 지출. 카드사로 결제수단·사용자 자동 매칭 |
| 카드 승인취소 | 원래 거래의 카테고리를 쓴 **음수 지출** (원 거래가 없으면 알림) |
| 해외 결제 | 그 통화 금액 + 입력 시점 환율 |
| 통장 **입금** | **수입** — 은행명으로 `자산` 통장·소유자 매칭, 메모는 적요 |
| 통장 **출금** | **지출** — 내 통장끼리 옮긴 돈이면 `내역`에서 구분을 `이체`로 고치기 |
| 카드 대금 출금 | 건너뜀 (카드 대금 자동 이체가 처리) |
| 같은 문자 또 붙여넣기 | 같은 날·금액·내용이면 **중복 건너뜀** |
| 인식 못 함 | `인식 실패`로 남음 → `내역`에 직접 입력 |

날짜는 `10/05` · `2026.10.05` · `10월 5일` 형식을 읽습니다. 카드는 카카오뱅크·토스뱅크·네이버페이 등도 인식하되, 결제수단 칸이 채워지려면 `자산`에 그 이름이 있어야 합니다.

### ⭐ 즐겨찾기

커피·점심처럼 자주 쓰는 내역을 등록하고 **A열을 체크**하면 오늘 날짜로 `내역`에 들어갑니다(체크는 자동으로 풀림). 금액이 달라지면 대표 금액으로 등록 → 체크 → `내역`에서 그 줄 금액만 고치세요. 금액이 비어 있으면 추가되지 않습니다.

### 🔁 반복

월세·구독·보험처럼 매달 같은 날 나가는 돈. **사용**을 체크해 두면 매일 06시에 해당 일자가 되면 자동 입력됩니다.

- 31일로 적으면 짧은 달은 말일에 들어갑니다.
- 이번 달 일자가 이미 지난 뒤 등록하면 **다음 달부터** 들어갑니다(중복 방지).
- 외화 구독은 오른쪽 끝 `통화`(N열)에 USD 등을 적습니다.
- 같은 달·같은 카테고리·같은 금액이 이미 있으면 건너뛰고 `마지막 생성 월` 칸에 메모를 남깁니다.
- **금액이 빈 항목**은 만들어지지 않고 빨갛게 표시됩니다.

## 3. 보기

| 탭 | 무엇을 보나 | 조작 |
|---|---|---|
| **대시보드** | 수입·지출·저축·남은 돈, 고정비/변동비, 카테고리 도넛, 예산 대비 사용, 사람별 지출, 카드 실적 | `C1` **◀ 이전 달 / 다음 달 ▶ / 이번 달**, 또는 `B1` 분홍 칸에서 월 선택 |
| **부부** | 사람별 수입·지출·저축, 카테고리×사람 예산, **공동 지출 반반 정산** | 월 선택은 대시보드와 동일 |
| **자산현황** | 목표 순자산 달성률·필요 월 저축, 올해 저축 목표, 월별 저축률, 자산 분포, 부채 | — |
| **자산기록** | 순자산 추이 그래프 (매일 06시 이번 달 줄 기록, 월말 값이 남음) | — |
| **고정지출** | 반복 항목을 카테고리별로 모은 월납입액·비율 | — |
| **카드** | 카드별 이번 달 사용액·실적 달성률, 혜택·연회비·결제일·결제 계좌 | 분홍 칸에 입력 |
| **저축·연금** | 저축·연금(수익률)·기타 자산 정리 | `자산` 종류로 구분 |
| **추이** *(숨김)* | 연간 월별 수입·지출, 카테고리×월 표, 연도 비교 | `C1` **◀ 이전 해 / 다음 해 ▶ / 올해** |
| **달력** *(숨김)* | 날짜별 지출 — 많이 쓴 날일수록 진하게 | `B1` 월 선택 |
| **검색** *(숨김)* | 키워드·기간·사용자로 내역과 합계 | 칸을 비우면 조건 없음. 날짜·금액 오류 줄은 합계에서 제외하고 건수를 알림 |

**정산 규칙** — 사용자를 `공동`으로 적은 지출을 결제수단 소유자(`자산` I열)가 낸 것으로 보고, 둘이 낸 금액 차이의 절반을 「누가 → 누구에게 얼마」로 보여 줍니다. 공동 소유 통장으로 낸 돈은 정산하지 않습니다.

## 4. 설정·자산

### ⚙️ 설정

| 항목 | 설명 |
|---|---|
| 카테고리 | 대분류(D열 **고정비/변동비**) 아래 중분류(A열). 맨 아래에 한 줄 쓰면 드롭다운에 바로 추가 |
| 구분(B열) | 새 이름(예: `저축`)을 쓰면 내역·반복·즐겨찾기 드롭다운에도 나옴. 수입·지출·이체가 아닌 구분은 「나가는 돈」으로 계산되어 대시보드 `저축·기타`에 합산 |
| 사람별 예산 | **K·L·M열** (신랑·신부·공동). C열 합계는 자동. 비우면 사용률은 안 보임 |
| 💡 예산 추천 | `J12` 체크 → **지난 3개월 평균**으로 K~M의 **빈 칸만** 채움 (1만 원 단위, 이미 적은 예산은 그대로). 결과는 `I13` |
| 월 시작일 | `J2`. 25로 바꾸면 25일~다음 달 24일을 한 달로 계산 (급여일 기준) |
| 예산 알림 | `J3` 켜기/끄기, `J4` 받을 메일(쉼표로 여러 개, 시트를 공유받은 사람만 발송) |
| 환율표 | `G:H`. USD·JPY·EUR·CNY 실시간 자동 |

**이름 바꾸기** — 카테고리·사용자·자산 이름을 **한 칸씩** 고치면 과거 내역·반복·즐겨찾기도 따라 바뀝니다. 여러 칸을 한꺼번에 붙여넣으면 자동 변경되지 않습니다.

### 🏦 자산

- 통장·카드·현금별 현재 잔액이 자동 계산됩니다.
- 청약·적금처럼 돈이 쌓이는 계좌는 F열 **적립 카테고리**를 고르면, 그 카테고리로 기록할 때마다 잔액이 늘어납니다.
- **같은 카드가 두 장**이면 `하나카드_신랑`, `하나카드_신부`처럼 **이름_소유자**로 적으세요(정산·잔액이 맞아집니다).
- G열 **연동**에 `메리츠_신랑` 등을 고르면 잔액이 증권 계좌 순자산으로 채워집니다.

### 💳 카드 대금 자동 이체

`카드` 탭에 **결제일**과 **결제 계좌**(자산 이름 드롭다운)를 적은 카드만 대상입니다. 결제일 06시에 카드 잔액(빚) **전액**을 `결제 계좌 → 카드` 이체로 만듭니다. 이번 달 그 카드로 들어가는 이체가 이미 있으면 건너뜁니다. 실제 청구액과 다르면 그 줄 금액을 고치세요.

## 5. 증권 연동

앱 Key는 **계좌 주인마다** 따로 받습니다. 시트 소유자는 `주식_신랑`·`메리츠_신랑`, 그 밖의 편집자는 `주식_신부`·`메리츠_신부`를 씁니다.

**각자 처음 한 번 — 자기 PC에서**

| 순서 | 메뉴 | 입력 |
|:---:|---|---|
| 1 | `증권 연동 → 메리츠 키 입력 (내 계좌)` | App Key · App Secret · MAC 주소(윈도우 `getmac`) |
| 2 | `증권 연동 → 한투 ISA 키 입력 (내 계좌)` | App Key · App Secret · ISA 계좌번호 10자리 *(한투가 있을 때)* |
| 3 | `증권 연동 → 자동 갱신 켜기 (내 계좌)` | — |

- 매일 **07시대·16시대** 자동 갱신. 각 주식 탭 `H1`의 **지금 갱신**을 체크하면 바로 갱신.
- `투자` 탭: 계좌별 평가금액·원금(종목 매입금액 합)·손익·수익률·현금(예수금), 전일/전월말 대비, 월별·최근 30일 추이. 자동 조회가 안 되는 계좌는 H·I열에 직접 입력.
- 메리츠 슈퍼365 발행어음·RP 자동투자분은 `자동투자 인출가능`에 따로 보이며 합계에는 더하지 않습니다.
- 🔒 키는 입력한 사람의 사용자 속성에만 저장됩니다(시트·git·상대방에게 없음). 노출이 의심되면 포털에서 재발급 후 다시 입력하세요. 지우려면 `내 키 삭제`.

## 6. 자동 기능

| 시각 | 하는 일 |
|---|---|
| 매일 06시 | 반복 지출 입력 → 외화 환율 고정 → 카드 대금 이체 → 예산 알림 → 순자산 기록 → 월간 결산(월 시작일) → 투자 기록 → **업데이트일 갱신** |
| 매일 07시대·16시대 | 증권 계좌 갱신 (각자 PC) |
| 입력 즉시 | 카테고리 추천, 외화 환율 고정, 이름 변경 반영, 구분 변경 반영 |

각 탭 오른쪽 위 **업데이트일**은 06시 자동 실행이 마지막으로 돈 날입니다(모든 탭이 같은 날짜). 어제 날짜에서 멈춰 있으면 자동 실행이 멈춘 것입니다.

📩 **메일** — 예산 80%·100% 초과 알림, 매달 결산(사람별 수입·지출·저축, 지출 상위 5개, 예산 초과, 공동 정산, 순자산 증감).

## 7. FAQ

<details><summary><b>고정지출이 안 들어와요</b></summary>

이번 달 일자가 이미 지난 뒤 등록한 항목은 중복을 막기 위해 **다음 달부터** 들어갑니다. `마지막 생성 월`에 이번 달이 찍혀 있으면 정상입니다. 금액이 빈 항목(관리비 등)은 만들 수 없어 빨갛게 표시됩니다.
</details>

<details><summary><b>내역 줄이 빨갛게 보여요</b></summary>

날짜·금액이 형식에 맞지 않거나 사용자가 빈 줄입니다. 고치기 전에는 대시보드 합계에서 빠집니다. 개수는 대시보드 위쪽 빨간 글씨 「확인 필요」에도 나옵니다.
</details>

<details><summary><b>대시보드가 0이에요</b></summary>

분홍 칸에서 고른 달에 내역이 없는지, 내역 날짜가 날짜 형식인지 확인하세요. 잘못되면 귀속월 칸에 `날짜오류`가 보입니다.
</details>

<details><summary><b>카드·통장 문자가 인식 실패예요</b></summary>

카드사·은행마다 문자 형식이 달라 일부는 못 읽습니다. 그 건은 `내역`에 직접 입력하세요. 날짜가 없는 알림도 인식하지 못합니다.
</details>

<details><summary><b>`내역`에 결제수단을 입력했는데 거부돼요</b></summary>

사용자·구분·결제수단·입금자산·통화는 목록에 있는 값만 받습니다. 새 통장·카드는 `자산`에 먼저 등록하세요. (카테고리는 경고만 합니다.)
</details>

<details><summary><b>실수로 지웠어요 / 엑셀로 받고 싶어요</b></summary>

PC에서 **파일 → 버전 기록 → 버전 기록 보기**로 되돌립니다. 엑셀은 **파일 → 다운로드 → Microsoft Excel(.xlsx)**.
</details>

<details><summary><b>숨긴 탭은 어떻게 열어요?</b></summary>

PC 시트 메뉴 **가계부**에서 `추이`·`달력`·`검색`·`내 주식 탭`·`내 메리츠 상세`를 열고, 다 보면 `꺼낸 탭 다시 숨기기`. 숨겨도 자동 기능은 그대로 돌아갑니다.
</details>

## ⚠️ 한계

- 외화 내역은 **입력 시점 환율**로 고정되지만, 환율을 못 가져오면 `환율오류`로 표시되고 합계에서 빠집니다.
- 이름 변경 자동 반영은 한 칸씩 수정할 때만 동작합니다.
- 사람별 예산 슬롯은 3개(`설정` E2:E4), 증권 계좌 슬롯은 2개 고정입니다.
- 은행·카드 실시간 연동과 위젯은 지원하지 않습니다.
- 시트 편집 권한자는 Apps Script 코드를 고칠 수 있고 갱신은 각자 권한으로 돌므로, 악의적 코드 수정으로 상대 키를 빼낼 수 있습니다(부부 공유 범위에서 수용).

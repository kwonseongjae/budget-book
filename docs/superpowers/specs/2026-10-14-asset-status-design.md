# 2부 — 자산현황 탭 (목표·저축률·부채)

## 목적

부부가 "목표까지 얼마 남았나, 매달 얼마나 모으나, 빚은 얼마인가"를 한 탭에서 본다.
지금 가계부는 순자산·주식·청약 합계만 있고 목표·저축률·부채가 없다.

## 결정 사항

- 대출은 [자산] 탭의 한 줄(종류 `대출`, 초기 잔액 음수)로 기록한다. 상환은 내역 `이체`(통장 → 대출)로 적어
  기존 잔액 계산(`formulas.asset_values`)이 그대로 잔액·순자산·자산기록에 반영되게 한다. 새 잔액 계산 없음.
- 대출 상세(금리·월 상환액·상환일·만기)는 [자산현황] 부채 표에 사람이 적는다.
- 목표값은 [설정] 항목·값 칸에 적는다.
- 보여 주는 곳은 새 탭 [자산현황](대시보드 바로 뒤). 대시보드에는 목표 달성률 한 칸(M5:M6)만 추가.
- 입력 칸은 기존 입력 색(노랑)으로 칠하고, 나머지는 수식.

## 입력

| 위치 | 내용 | 예 |
|---|---|---|
| 설정 I8:J8 | 목표 순자산 | 300,000,000 |
| 설정 I9:J9 | 목표 기한 (yyyy-mm, 그 달 말일까지) | 2029-12 |
| 설정 I10:J10 | 올해 저축 목표 | 30,000,000 |
| 자산 B열 선택지 | `대출` 추가 (기존: 통장·계좌·카드·현금·청약·주식) | |
| 자산현황 부채 표 | 대출명(자산 탭 `대출` 목록 드롭다운), 금리, 월 상환액, 상환일, 만기(yyyy-mm), 비고 | |

설정 I5:J7은 비워 둔다(운영 I6에 안내 문구). 운영 I8:J10은 비어 있음(2026-10-14 확인).

## [자산현황] 탭 구성 (위에서 아래)

1. 목표 카드
   - 현재 순자산(= 자산 탭 현재 잔액 합, 대시보드 J6과 같은 값), 목표 순자산, 달성률
   - 남은 개월 = 목표 기한 말일까지 개월 수(올림), 필요 월 저축 = (목표 − 현재) ÷ 남은 개월
   - 올해 저축 누적(아래 표 합), 올해 저축 목표, 달성률
2. 월별 저축률 (올해 1~12월, 연도는 오늘 기준)
   - 열: 월 · 수입 · 소비지출 · 저축 · 저축률
   - 수입 = 구분 `수입`, 소비지출 = 구분 `지출`(저축·이체 제외), 저축 = 수입 − 소비지출, 저축률 = 저축 ÷ 수입
   - 귀속월(내역 L열) 기준. 수입 0인 달은 저축률 빈칸.
   - 그래프: 막대(수입·소비지출) + 꺾은선(저축률, 오른쪽 축)
3. 자산 분포
   - 묶음: 현금성(현금·통장·계좌), 주식, 청약, 부채(카드·대출). 금액·비율 표.
   - 원형 그래프는 플러스 묶음(현금성·주식·청약)만. 부채는 표에만.
4. 부채 표
   - 사람 입력: 대출명, 금리, 월 상환액, 상환일, 만기, 비고
   - 자동: 소유자·현재 잔액(자산 탭에서 대출명으로 찾음), 남은 개월(만기까지)
   - 합계 줄: 잔액 합, 월 상환액 합

## 대시보드

M5 `목표 달성률`, M6 = 자산현황 달성률 참조(백분율). 라벨·숫자 서식은 J5:L6 자산 현황과 같게.
운영 대시보드 M1:M18은 비어 있음(2026-10-14 확인). M19부터는 원형 그래프 이름표.

## 색·정렬

기존 규칙 따름: 수입 빨강·지출 파랑, 손실(음수) 파랑, 숫자 오른쪽·글자 가운데. 부채 잔액은 음수라 파랑.

## 오류 대비

- 목표 비어 있음 → 달성률·필요 월 저축 빈칸 (오류 없음)
- 기한이 지났거나 이번 달 → 남은 개월 0, 필요 월 저축 칸에 "기한 지남"
- 부채 표 대출명이 자산 탭에 없음 → 잔액 칸 "자산 탭에 없음"
- 운영 적용은 migrate_couple.py(두 번 실행해도 안전): 탭이 없을 때만 추가, 값·서식은 덮어써도 안전한 칸만.
  부채 표 사람 입력 칸은 첫 생성 때만 머리글을 쓰고 이후 값은 건드리지 않는다. 적용 전 백업.

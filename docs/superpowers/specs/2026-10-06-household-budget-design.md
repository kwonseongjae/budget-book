# 부부 가계부 (Google Sheets) 설계 — v2

## 목표
- 부부 2인이 PC·폰(구글 시트 앱)에서 수입/지출/이체를 추가·삭제·수정한다.
- 어디에 얼마 썼는지 차트로 한눈에, 월별·연도별 추이까지 본다.
- 카테고리·사용자·결제수단 드롭다운은 사용자가 직접 추가·수정(이름 변경 시 과거 내역 자동 반영).
- 인기 가계부 앱 Top3(뱅크샐러드, 편한가계부, 토스)의 필수 기능 중 시트로 구현 가능한 것은 모두 넣는다.
- 추후 확장(폼, 웹앱 입력 등)이 기존 구조를 깨지 않아야 한다.

| F10 | 소분류 (편한) | 내역 `소분류` 열 (자유 입력, 시트 자동완성) |
| F11 | 검색 (편한) | 검색 탭: 키워드·기간 입력 → `QUERY` 결과 |

| F13 | 다중 통화 (편한) | 내역 `통화` 열(기본 KRW) → `GOOGLEFINANCE` 환율로 원화 환산 |
| F14 | 소비 리포트: 전월 대비 증감, 일평균, 월말 예상 (뱅샐·토스) | 대시보드 요약 영역 |
| F15 | 예산 초과 알림 (뱅샐·토스) | 매일 트리거: 사용률 80%/100% 넘으면 부부에게 이메일 1회 |
| F16 | 공동/개인 지출 구분 (부부 앱 공통) | 사용자 목록에 `공동` 기본 포함 |
| F17 | 공유·동기화·비밀번호·백업·엑셀 내보내기·음성 입력·영수증 첨부 | **시트 기본 기능으로 충족** (공유, 구글 계정 보안, 버전 기록, 파일>다운로드, 키보드 마이크, 셀에 이미지 삽입) — 코드 없음 |

### 구현 불가 (대안)
- **은행/카드 자동 연동(마이데이터)**: 마이데이터 사업자 인가가 필요해 개인 시트로는 불가 → F9(문자 붙여넣기)로 대체.
- **SMS 자동 읽기, 홈 화면 위젯**: 앱 권한이 필요해 불가 → 시트 바로가기를 홈 화면에 추가하도록 안내.

## 구현 방식
1. `build_budget.py`: Google Sheets API(`batchUpdate`)로 스프레드시트 생성(탭·검증·수식·차트·조건부서식·보호) → 배우자 이메일에 편집 공유.
2. `deploy_script.py`: Apps Script API로 시트에 연결된(bound) 스크립트 생성 후 `apps-script/*.gs` 업로드.
3. 사용자가 시트에서 **1회** `확장 프로그램 > Apps Script > setupTriggers 실행 → 권한 허용` (설치형 트리거는 API로 만들 수 없음). 안내는 README에 단계별로.
- 인증: `~/wedding-sheets` 의 `sheets_client.py` / `auth_script_api.py` 흐름 재사용. 토큰은 이 폴더에 별도 발급(`.gitignore`). `client_secret.json` 경로·배우자 이메일은 환경변수(`BUDGET_CLIENT_SECRET`, `BUDGET_PARTNER_EMAIL`)로 받고 없으면 에러.
- **모바일 제약**: 시트 앱에서는 커스텀 메뉴·사이드바·버튼이 동작하지 않는다. 그래서 모든 스크립트 동작은 **체크박스 체크(onEdit)** 또는 **시간 트리거**로 시작한다.

## 탭 구조

### 내역 (유일한 데이터 원천)
| 열 | 내용 | 입력 |
|---|---|---|
| A 날짜 | 날짜 | 날짜 검증(달력) |
| B 사용자 | 이름 / 공동 | 드롭다운 ← 설정 |
| C 구분 | 수입 / 지출 / 이체 | 드롭다운(고정) |
| D 카테고리 | | 드롭다운 ← 설정 (이체는 비움) |
| E 소분류 | | 자유 입력 |
| F 결제수단 | 자산명 (이체면 출금 자산) | 드롭다운 ← 자산 |
| G 입금자산 | 이체일 때만 | 드롭다운 ← 자산 |
| H 금액 | 양수 | 숫자 > 0 |
| I 통화 | KRW 기본 | 드롭다운 ← 설정 통화 목록 |
| J 메모 | | 자유 |
| K 원화금액 | 계산 열(보호): `ARRAYFORMULA` 로 H×환율 | 자동 |
| L 귀속월 | 계산 열(보호): 월 시작일 기준 `YYYY-MM` | 자동 |

- 모든 집계는 K(원화금액)·L(귀속월)을 쓴다. 집계 수식은 열 전체 참조라서 행을 추가·삭제·정렬해도 깨지지 않는다.
- 확장 원칙: 모든 입력 경로(즐겨찾기·반복·문자·미래의 폼/웹앱)는 이 탭 끝에 한 행을 추가(append)하는 공용 함수 `appendTxn()` 하나만 사용한다.

### 설정
- 카테고리 표: `카테고리 | 구분(수입/지출) | 월 예산`. 행을 추가하면 드롭다운에 자동 반영(열린 범위 검증).
- 사용자 목록(기본: 사용자1, 사용자2, 공동), 통화 목록(KRW, USD, JPY, EUR), 월 시작일, 알림 on/off, 알림 받을 이메일.
- 조회 월/연도 선택은 폰에서 탭을 오가지 않도록 각 보기 탭(대시보드·추이·달력) B1 드롭다운에 둔다. 비우면 이번 달/올해.
- **이름 변경 자동 반영**: 설정 탭에서 카테고리·사용자 이름을 바꾸면 `onEdit` 이 `e.oldValue → e.value` 로 내역 해당 열을 일괄 치환한다. 자산 이름은 자산 탭에서 같은 방식으로 처리한다.
  - 한계: 셀 하나씩 수정할 때만 `oldValue` 가 넘어온다. 여러 칸을 붙여넣어 바꾸면 치환되지 않는다(검증 경고가 표시됨). 설정 탭에 이 안내 문구를 둔다.
  - 행을 삭제한 카테고리의 과거 내역은 그대로 둔다(검증 경고 표시).

### 자산
`자산명 | 종류(통장/카드/현금) | 초기 잔액 | 월 실적 목표 | 현재 잔액(수식)`
- 현재 잔액 = 초기 잔액 + 이 자산의 수입 + 입금된 이체 − 이 자산의 지출 − 출금된 이체.
- 카드는 "이번 달 사용액 / 실적 목표"로 표시한다.

### 대시보드 (보기 전용·보호, 조회 월 기준)
1. 요약: 수입 · 지출 · 잔액 · 전월 대비 지출 증감(%) · 일평균 지출 · 월말 예상 지출(일평균 × 해당 월 일수)
2. 카테고리별 지출 도넛 차트
3. 예산 대비 사용 막대 차트 + 사용률 표(100% 초과는 빨강, 80% 이상은 주황)
4. 사용자별 지출 막대 차트 (공동 포함)
5. 카드 실적 달성률 표

### 추이 (보기 전용·보호)
1. 조회 연도 1~12월 수입/지출/잔액 콤보 차트
2. 카테고리×월 지출 표(히트맵)
3. 연도별 수입/지출/잔액 막대 차트(내역에 있는 모든 연도)

### 달력 (보기 전용·보호)
조회 월 기준 7×6 그리드에 날짜와 그날 지출 합계를 표시. 많이 쓴 날일수록 진한 색.

### 검색
키워드(메모·소분류·카테고리 포함 검색), 시작일, 종료일, 사용자를 입력하면 `QUERY` 로 결과 표와 합계를 보여준다.

### 반복
`사용 여부(체크) | 매월 일자 | 사용자 | 구분 | 카테고리 | 결제수단 | 금액 | 메모 | 마지막 생성 월(자동)`
- 매일 새벽 트리거가 오늘이 해당 일자인 항목을 추가한다. 해당 월 일수보다 큰 일자(예: 31일)는 그 달 말일에 추가한다. `마지막 생성 월` 로 같은 달 중복 생성을 막는다.

### 즐겨찾기
`추가(체크박스) | 사용자 | 구분 | 카테고리 | 결제수단 | 금액 | 메모`
- 체크하면 오늘 날짜로 내역에 추가하고 체크를 해제한다. 금액이 비어 있으면 추가하지 않고 셀 메모로 알린다.

### 문자입력
A열에 카드 승인 문자 여러 건을 붙여넣고 B1 체크박스를 체크하면 파싱한다.
- 추출 대상: 날짜(MM/DD), 금액(`[\d,]+원`), 가맹점명. 승인취소 문자는 건너뛴다.
- 결제수단은 문자에 나온 카드사명으로 자산 탭에서 찾고, 카테고리는 비워 둔다(검증 경고로 입력 유도).
- 파싱하지 못한 줄은 C열에 "인식 실패"로 남긴다.
- 카드사마다 문자 형식이 달라서 정규식은 실제 문자 샘플로 보강한다. 테스트 샘플은 주요 4개 카드사(신한·국민·삼성·현대) 형식으로 시작한다.

### 알림
매일 트리거가 조회 월이 아닌 **현재 월**의 카테고리별 사용률을 계산해 80% 또는 100%를 처음 넘으면 부부 이메일로 1회 발송한다. 발송 기록은 숨김 탭 `알림기록` 에 남겨 중복 발송을 막는다.

## 기본 데이터
- 지출 카테고리: 식비, 카페·간식, 생활용품, 주거·관리비, 통신, 교통, 의료, 쇼핑, 문화·여가, 경조사, 기타
- 수입 카테고리: 월급, 부수입, 기타수입
- 자산: 현금(현금), 주거래통장(통장), 신용카드1(카드) — 사용자가 수정
- 예산·실적 목표는 빈 칸. 비어 있으면 사용률 표시를 생략한다.

## 검증 / 테스트
- **Python (pytest)**: `sheet_spec.py` 의 요청 빌더가 만드는 JSON(탭, 검증 범위, 수식 문자열, 차트 소스 범위)을 검사한다.
- **Apps Script 로직**: 시트에 의존하지 않는 순수 함수(문자 파싱, 반복 일자 계산, 이름 치환 대상 계산, 알림 임계값 판정)는 `logic.gs` 로 분리하고 Node(`node --test`)로 단위 테스트한다. `.gs` 파일을 `vm` 으로 불러와 실행한다.
- **통합**: 실제 시트를 만든 뒤 API로 샘플 내역을 기록하고, 대시보드·추이·자산 셀 값을 읽어 기대 합계와 비교한 다음 샘플을 삭제한다.
- **수동(폰)**: 행 추가·수정·삭제, 카테고리 추가와 이름 변경 반영, 즐겨찾기 체크, 문자 붙여넣기.
